## Recommended lever family (heuristic)

- blend kernel is `host-dominated`: the `device_fw_max` is   8.60 ms vs host wall  24.57 ms. Host-side lever family: batched upload, persistent inputs, Trace API, 2-CQ pipeline, smaller per-frame DRAM payloads. Device-side levers still independently valid — `device_fw_max` is itself a real floor that compounds with any host wins. Per-RISC table above identifies the dominant RISC; pursue both in parallel if zone data justifies it.
- `project` is  17.98 ms =  16.5% of total. Sub-stage table above identifies which PyTorch op is the hot spot (typically `cov3d` or `cov2d` per-Gaussian batched matmuls).

_All numbers are medians over the measured cycles. The verdict above is a heuristic starting point — confirm with the per-RISC + sub-stage tables before committing to an iter plan._
